誰在使用 psutil¶

psutil is among the top 100 most-downloaded packages on PyPI, with 390+ million downloads per month and 780,000+ GitHub repositories using it. The projects below are a sample of notable software that uses it. They are grouped by how much of the project depends on psutil, and every usage links to the code that calls psutil. See also 替代方案 for related Python libraries and equivalents in other languages.

Datadog
Agent checks read processes, disks and network through psutil.
see the code write-up
Ray
Ships psutil in its own wheel; OOM monitor, process watcher, autoscaler.
see the code
Home Assistant
CPU, memory and disk for the system monitor integration.
see the code
OpenTelemetry

How this list was compiled¶

Candidates came from the GitHub dependency graph and from code search. Each one was then checked against the project's packaging metadata and source, to make sure psutil is a real dependency and not just a mention. The links in the last column point at the code doing the work, pinned to a commit so the line numbers keep matching.
